# nsh 版纯文本邮件在暗色主题下用暗色背景

- 日期：2026-11-05
- 类型：修复

## 背景

catmail-nsh 在暗色外观下打开只有纯文本、没有 HTML 部分的邮件，读信区是白底。复现条件：外观为暗色，邮件只有
text/plain 部分。

## 决策

页面用暗色还是亮色，原来只看 `recolor_html` 有没有结果：HTML 能着色就用暗色，否则用亮色，让邮件自己的颜色保持
原样。纯文本邮件没有 HTML 可着色，也就落到了亮色。可是纯文本本身没有颜色，应该直接用主题的颜色。gpui 版里
纯文本也是跟着主题走的。

## 方案

`reader.rs` 新增 `page_is_dark(dark, html, recolored)`：读信区是暗色时，HTML 着色成功或者是纯文本，就用暗色；
着色不了的 HTML 仍用亮色。测试 `plain_text_takes_the_dark_theme` 覆盖这几种情况，修复前纯文本那一条不通过。
