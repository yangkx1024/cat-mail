# 亮色与暗色应用图标

- 日期：2026-10-26
- 类型：功能

## 背景

应用需要一枚猫脚印叠在信封上的图标，优先使用可缩放的 SVG，并支持亮色和暗色环境。

## 决策

使用略微倾斜的暖白信封、橘色猫脚印和圆角底板；暗色底板使用深绿灰。
直接绘制矢量路径，不引入位图或字体。提供媒体查询自动配色版本，以及不依赖 CSS 的两个固定版本，
以兼容不支持系统主题查询的桌面图标加载器。本次只提供资源，不改动窗口或系统打包配置。

## 方案

资源位于 `crates/catmail-gui/assets/app-icon/`，画布为 512 × 512，README 说明各版本的用途。
使用 XML 解析检查三份 SVG，并用 librsvg 渲染检查亮暗版本的 512、64、32 像素输出。
